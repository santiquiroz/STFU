# F4 — UI del hub de modelos + estado del sistema: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dar interfaz al hub de modelos (F2) y al hardening del APO (F3), que hoy están 100% en el backend y 0% en el frontend: navegar/descargar/activar/borrar modelos con selector de device, y un panel de estado que muestra salud del APO (needs-repair + repair) y degradación de inferencia.

**Architecture:** El frontend es diminuto (React 19 + TanStack Query v5 + Tailwind v4, tema dark zinc/green, sin router, sin componentes extraídos, sin tests). F4 introduce navegación por tabs (sin dependencia de router — `useState` en App), extrae un puñado de primitivos reutilizables (Badge, Card, Spinner) de los patrones inline de `Simple.tsx`, agrega la capa de servicio + hooks para `/models`, `/apo/health`, `/apo/repair`, y construye dos superficies nuevas: la página **Modelos** (catálogo curado+instalado) y la página **Sistema** (salud APO + estado de inferencia). El control de mic actual (Simple) pasa a ser la tab **Control**.

**Tech Stack:** React 19, TanStack Query 5, axios, Tailwind CSS v4, TypeScript 5.8, Vite 7, Tauri 2. Sin dependencias nuevas. Testing: `tsc --noEmit` como gate por task + un smoke E2E con Playwright contra el backend real al final.

**Spec:** `docs/superpowers/specs/2026-08-18-stfu-modernization-design.md` (§8, y las superficies de §3.5/§4.3/§7 que F2/F3 dejaron sin UI)

## Global Constraints

- Base: master post-merge de F1+F2+F3 (merge commit `51f4fa3`). Backend intacto — F4 es solo `frontend/src`.
- Correr desde `frontend/`: `npm run type-check` (`tsc --noEmit`) debe pasar en cada task. `npm run build` (`tsc && vite build`) verde al final.
- Reusar el tema existente: dark, paleta `zinc` (shell `zinc-900`, cards `zinc-800`, inputs `zinc-700`), acento `green-500` para activo/enabled, banners tintados `red/amber/green-950`, `rounded-xl`, texto chico, copy en **español**, glifos emoji como iconos. Consistencia visual con `Simple.tsx`.
- Diseño intencional (no template): jerarquía por escala, badges semánticos (no decorativos), estados hover/focus/active diseñados, grid con ritmo. Evitar el card-grid uniforme sin jerarquía.
- El endpoint de descarga es **síncrono/bloqueante** (no hay stream de progreso): la UI de descarga es un spinner indeterminado + estado deshabilitado, no una barra de %.
- Commits en español, formato convencional. Sin `Co-Authored-By`.
- No romper el flujo feeder existente (el control de mic sigue funcionando).

```typescript
// frontend/src/hooks/useModels.ts
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { api } from "../services/api";

export function useModels() {
  return useQuery({ queryKey: ["models"], queryFn: api.listModels, staleTime: 30_000 });
}

export function useDownloadModel() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (id: string) => api.downloadModel(id),
    onSuccess: () => qc.invalidateQueries({ queryKey: ["models"] }),
  });
}

export function useActivateModel() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (v: { id: string; target: string; device: string }) =>
      api.activateModel(v.id, v.target, v.device),
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: ["models"] });
      qc.invalidateQueries({ queryKey: ["status"] });
    },
  });
}

export function useDeleteModel() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (id: string) => api.deleteModel(id),
    onSuccess: () => qc.invalidateQueries({ queryKey: ["models"] }),
  });
}
```

```typescript
// frontend/src/hooks/useSystemHealth.ts
import { useMutation, useQuery, useQueryClient } from "@tanstack/react-query";
import { api } from "../services/api";

export function useApoHealth() {
  return useQuery({ queryKey: ["apo/health"], queryFn: api.getApoHealth, refetchInterval: 10_000 });
}

export function useRepairApo() {
  const qc = useQueryClient();

    onSuccess: () => {

  });
}
```
